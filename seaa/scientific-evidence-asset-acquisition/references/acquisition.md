# 获取与核验路线

## 先审 Given，再针对缺口找

盘点来源类型（用户原始实验、处理结果、未经核查陈述、原始论文、综述、其他权威来源），核实际已读范围、版本和日期。原件只读，计算或绘图只写派生文件；大文件可分批核查，记录真实范围。可先运行：

```text
python SKILL_DIR/scripts/audit_files.py --out AUDIT.json INPUT1 INPUT2
```

脚本无需外部依赖，给真实绝对路径、大小、SHA-256、简单格式识别；对 CSV/TSV 给结构性缺失、坏行和完全相同行统计。它不推断重复行一定错误、实验重复是否独立、异常值是否该删，不计算无依据的误差/显著性。输出完整读与读取失败分账。XLSX/DOCX/PDF/PPTX 的内容用对应可用技能读取；先检查实际工具与依赖，不拿文件名猜内容。

对于实验数据，按当前主张核样品/批次、原始量与变换、单位/定义、仪器设置、浓度/温度/时间等条件、匹配空白/对照、样本量、技术与生物重复、缺失/排除、校准与统计。不相关项写不适用；未知项不补值。光谱只展示真实观测，机理推论不升级为已证实过程。

## 真实检索链

1. 从任务书的 C/R/S/V 提取问题、要支持/质疑的具体关系、必需证据和完成条件。优先走已指定 DOI、出版社文章、补充材料、数据仓库或用户文件的精确定位；没有确定入口时，才用学科术语/方法/限定条件生成可执行中英查询。
2. 依任务选基础、路线、原始、前沿、批判与素材层。明确时间窗口、纳排条件、必须提取项和相反结果。前沿、引用及具体论文核验必须使用当前可用搜索/网页工具打开原始页面；记录实际搜索日期与已搜范围。未知 DOI 不猜；一次未检出不是“文献不存在”。
3. 对论文核题名/作者/年份/期刊/DOI 或稳定链接、发表类型、同行评审信息、修订/撤稿提示和实际已读范围。原始研究优先；引用综述时追踪关键原实验。只拿到摘要就只标摘要，不把未读方法或 SI 填为已核条件。
4. 文章入口失效时换同一来源的合法版本、作者/机构库或数据仓库；记录换路原因及版本差别，不绕过登录/付费访问条件，不把下载到了 HTML 当 PDF。未知限制保留 unknown。对与预期冲突的来源同样记录纳排理由。
5. 平台/连接器是按当前能力选择的工具，不假定有订阅或所有附件都能获取。达到某 R 的具体完成判据即收尾；无结果时记录尝试范围、未获项、下一责任方及条件，不标成证据齐全。

## 从来源到证据，再到素材

一条 E 应对应明确的观测、分析或论据：记录来源中的具体页/图/表/数据行，方法、对象、指标定义和单位、实验条件、对照、重复/误差、适用范围、局限与替代解释；按相应 C 标支持、反对或仅提供背景。同一证据对不同 C 可有不同作用，不能对同一 C 同时标支持与反对而不拆清内容。

比较另作审查：对象、指标/单位/定义、测量/反应条件、控制组、统计和应用范围是否一致。DIRECTLY_COMPARABLE 必须逐维说明；CONDITIONAL 写所需转换及其依据，保留原值；NOT_COMPARABLE/UNKNOWN 不出排名图。不可解释的冲突原样保留，不强行合并平均。归一化、估读、拟合、单位转换保存代码/规则、输入和精度；不能以归一化掩盖样本/仪器差别。

素材 A 记录定位、精确原图号/数据位置、关联 E、科学含义、原始图注与必要条件、许可/署名、文件实际路径、指纹/格式/分辨率/编辑性（未知留 null）。LOCATED 仅为已定位；ACQUIRED 必须文件存在且指纹相符，不等于获准复用或内容已经核对。

实际取图/表时遵循当前文件技能：对合法取得的 PDF 可用 PyMuPDF 的页面/图像读取或现有 PDF 工具提取，记录文件页和印刷页的区别；PPTX 用只读 OOXML/已有解析器定位素材，不声称从截图取得原始数据。真实数据重绘留转换链；原图裁边仅去无信息空白，不裁轴标、图例、样本标识或条件，保持原件。AI 示意图只作明确标注的示意，不作实验证据。公开可见不等于可复用，许可应落实到具体素材，科学内容与转载权分别审查。

下游遇到素材分辨率或版式不足，只返回 A/E/S/V 与实际问题；科学替代、数据合并或新结论由任务统筹复核。科学证据不变的格式转换仍记录新的 A 和变换步骤。
